🤖 Agéntica
Infraestructura de agentes de IA autónomos diseñada para la automatización integral de procesos de negocio. Este sistema prioriza la privacidad, la eficiencia y el control total de la infraestructura mediante procesamiento local y el uso de modelos de código abierto (open-source), eliminando por completo la dependencia de APIs externas. ⚙️

🎯 Principios del Sistema
Soberanía de Datos: Toda la información confidencial permanece estrictamente dentro de la infraestructura de la empresa. 🔒

Ejecución Local: Los modelos de lenguaje se despliegan de forma nativa en servidores propios utilizando Ollama. 🖥️

Arquitectura Multi-Agente: Implementación de agentes especializados que colaboran de manera eficiente mediante un sistema de supervisión jerárquica. 👥

🚀 Estado Actual del Desarrollo
Extracción de Entidades: Procesamiento y estructuración de datos desde texto no estructurado utilizando LLMs locales.

Capa de Datos: Integración con bases de datos relacionales para la gestión del conocimiento del dominio.

🛠️ Stack Tecnológico
Lenguaje: Python 3.8+

Orquestación de LLMs: Ollama (Despliegue local de modelos como Llama y Qwen)

Base de Datos: SQLite

💻 Instrucciones de Uso
Bash
python main.py          # Inicializa la base de datos e inserta los datos de prueba
python test_cliente.py  # Ejecuta el pipeline de extracción de entidades del producto

🤖 Agéntica
An autonomous AI agent infrastructure designed for end-to-end business process automation. This system prioritizes data privacy, efficiency, and full infrastructure control by leveraging local processing and open-source models, completely eliminating reliance on external third-party APIs. ⚙️

🎯 Core Principles
Data Sovereignty: All sensitive company data remains strictly within the internal infrastructure. 🔒

Local Execution: Large Language Models (LLMs) are deployed natively on self-hosted servers using Ollama. 🖥️

Multi-Agent Architecture: Specialized AI agents collaborating seamlessly through a hierarchical supervision structure. 👥

🚀 Current Project Status
Entity Extraction: Processing and structuring data from unstructured text using local LLMs.

Data Layer: Relational database integration for robust domain knowledge management.

🛠️ Tech Stack
Language: Python 3.8+

LLM Orchestration: Ollama (Local deployment of open-source models such as Llama and Qwen)

Database: SQLite
